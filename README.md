# GitHub-Commits

> Educational Next.js app that visualizes git commit history as a learning tool

A Next.js + TypeScript project that doubles as a learn-by-doing playground for Git workflow concepts. Includes a structured `plans/` folder with architecture, frontend enhancement, and spec documents, plus a hand-written commit log narrating each feature as it was built.

🔗 **Live repo:** <https://github.com/girishlade111/GitHub-Commits>

## ✨ Features

- Narrative `edu-commit-log.txt` documenting each feature commit with timestamps
- Architecture, frontend, and spec docs in the `plans/` folder
- Strict-mode Next.js setup with App Router
- Tailwind + PostCSS for utility-first styling
- Educational reference for teaching incremental Git workflows

## 🛠️ Tech stack

Next.js 14 • React 18 • TypeScript • Tailwind CSS • PostCSS

## 🚀 Getting started

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```
